# NIGHT SIGNALS — 3D Vinyl Album (CSS-only prototype)

A standalone visual experiment: a paper sleeve with a vinyl record
partially pulled out of the right-hand opening, spinning continuously
on its own axis. Built entirely with HTML, CSS 3D transforms, and
vanilla JavaScript. No frameworks, no WebGL, no build step.

## Launch it

**Option 1 — double-click `index.html`.**

**Option 2 — tiny local server (recommended for Firefox/Safari):**

```bash
cd vinyl-album-3d
python3 -m http.server 8080
# then open http://localhost:8080
